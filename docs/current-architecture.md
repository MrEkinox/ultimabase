# Current architecture index

This living index answers one question: where is the current contract for an
architectural concept? It routes contributors to the maintained contract, the
code that owns it, and the accepted decisions that explain it. It does not
replace those sources or make historical plans authoritative.

The code is a rebuild of the reference implementation (commit
`0ae7767f7b75dd6c640ca547f9ff85b60f46e69d`) with an unchanged public contract;
see [the project history](../ARCHITECTURE.md#history).

Use the sources in this order:

1. code and conformance tests define shipped behavior;
2. root specifications and package contracts define the maintained boundary;
3. accepted ADRs explain durable decisions and constraints;
4. the Git tags `reference-archive` and `rebuild-archive` retain the
   implementation history (issue backlog, plans, rebuild records) only.

Historical ADRs remain immutable evidence. A superseding ADR changes which
record is current; it does not erase the older record. An ADR or archived record
that names an internal module describes the reference layout; use the
[module layout](../ARCHITECTURE.md#module-layout) for the current one.

## Retained typing boundaries

These are accepted limits, not fresh experiments to repeat on each task.
[ADR-0297](adr/0297-declare-schemas-without-typegen.md) is the only declaration
form: `define({ className, fields, indexes })`, thunk relation targets, shape
methods, a final `.with(...)` for plugin rules, and one required `Register`
declaration for name-keyed types. Typegen and the old form (plugin options
inside `define`) were removed in migration step 6.8b; the Typegen-era records
are superseded by ADR-0297, entirely or for their Typegen parts (see the ADR
catalog).

- `mappedBy` of a thunk target is checked when the application is constructed,
  not on its line; `.with` must stay the last call (ADR-0297).
- The fix of the `Register` cycle relies on how TypeScript defers conditional
  types (ADR-0297, register-cycle note). Its reproduction cases
  (`tests/register-cycle`) run in the TypeScript 7 CI job from sources and
  built packages, and `register-required.e2e.test.ts` guards it on
  TypeScript 6; rerun the cases on TypeScript 6 at each TypeScript upgrade.
- Editor speed follows the revised thresholds of ADR-0297 (2026-10-13),
  measured with the form D bench: TypeScript 7 is the reference and
  TypeScript 6 a regression guard.
- A plugin field kind's filter is typed as null checks only; its portable
  equality is a Runtime contract.
- Nested plugin-option JSDoc hover can be missing while completion, diagnostics
  and exact types remain (archived evidence: issue 6310 at tag `reference-archive`).
  Core must not hard-code plugin option names to recover documentation.
- Readable item hovers take priority over discarded flattening optimizations
  (failed experiment evidence: issue 6316 at tag `reference-archive`).

Reopening requires new concrete compiler/consumer evidence and explicit
approval; do not revive removed bridges.

## Maintenance rule

Update this index in the same change whenever an accepted ADR changes one of
these concepts, a refactor moves its responsible module, or a decision is
superseded. The repository documentation tests validate routes and reject a
listed ADR whose status is no longer current.
