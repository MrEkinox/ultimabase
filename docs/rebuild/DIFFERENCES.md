# Behavior differences from the reference

Every observable difference between the reconstruction and reference commit
`0ae7767f7b75dd6c640ca547f9ff85b60f46e69d` is listed here. The goal is none;
an entry exists only when reproducing the reference would require knowingly
unsafe code or when a reference defect was found.

| Area                                                      | Reference behavior                                                                                                                                                                                                                                            | Reconstruction behavior                                                                                    | Reason                                                                                              | Test coverage                                                     |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| hooks-plugin schema-mutation hook groups                  | A hook branch literally keyed `__proto__` (only reachable through `JSON.parse`/`defineProperty`) is assigned onto `Object.prototype` during normalization and silently dropped.                                                                               | Rejected at startup as `Unknown schema mutation Hook branch`.                                              | Reproducing it requires prototype-polluting code; the reference result is a latent security defect. | No reference test covers this input.                              |
| core `enumField`                                          | A values mapping with an own `__proto__` key (only reachable through `JSON.parse`/`defineProperty`) loses that key from `options.values` while the value is still accepted.                                                                                   | The key is kept as an own key of `options.values`.                                                         | The reference result is a prototype-assignment defect; the rebuild copies entries safely.           | No reference test covers this input.                              |
| core `decimalField(null)`                                 | Untyped JavaScript only: fails with the engine error `Cannot read properties of null (reading 'precision')`.                                                                                                                                                  | Throws `TypeError: field options must be an object`, like every other scalar field factory.                | Shared options validation; the reference message was an accidental engine error.                    | No reference test covers this input; TypeScript rejects the call. |
| core `exposeOperations` / `exposeSchemaMutations` results | Class instances whose TypeScript-`private` constructor parameters were enumerable own properties at runtime: `exposed` (map of compiled commands), `runtime` (whose `execute` skips envelope, cancellation and transaction-policy checks) and `createEngine`. | Frozen records with only `operations`, `transport` and `execute`. The public TypeScript type is unchanged. | Reproducing the old shape would knowingly hand transports unchecked execution handles.              | No reference test reads those properties; no package uses them.   |
| postgres-plugin field named `__proto__`                   | Core accepts the name, but the adapter built selections, record copies, update sets, projections and the Drizzle relation config with plain assignment, so the field was silently dropped (the write replaced the object's prototype).                        | The key stays an ordinary own key (`Object.fromEntries` / `Map`).                                          | Reproducing it requires prototype-assignment code.                                                  | No reference test covers this input.                              |
| access-plugin static `where` rules                        | A static `where` object with an own `__proto__` key (only through `JSON.parse`) was copied with plain assignment, so the key vanished and the private row filter became empty: the rule failed open.                                                          | The key is kept; Core rejects it with `where.__proto__ must reference a schema field`.                     | Reproducing it would knowingly keep a fail-open authorization defect.                               | No reference test covers this input.                              |
| access-plugin custom-mutation Access branches             | An Access branch keyed `__proto__` was silently dropped.                                                                                                                                                                                                      | Compilation throws `Unknown request schema mutation Access branch: access.__proto__`.                      | Same prototype-assignment defect; a dropped rule fails open.                                        | No reference test covers this input.                              |
| http-plugin original header snapshot                      | Each header slot (`header[0]`) was read up to three times; an array whose index slots are getters returning different values could keep an unvalidated non-string value.                                                                                      | Each slot is read once and the validated value is kept.                                                    | Closing a validation time-of-check/time-of-use gap; ordinary arrays behave identically.             | No reference test covers this input.                              |
| testing conformance typegen `verify` callback             | Called as a method of Core's internal copy of the check options, so a non-arrow `verify` saw that record as `this`.                                                                                                                                           | Called as a plain function (`this` is `undefined`); the context argument is unchanged.                     | The receiver was an implementation detail, not a documented contract.                               | No test reads `this`.                                             |
| testing conformance application class                     | One nested `UltimaBase` subclass per fixture plugin.                                                                                                                                                                                                          | One subclass built with `UltimaBase.use(...plugins)`; the prototype chain is shallower.                    | Same plugins in the same order; only prototype depth differs.                                       | Conformance suites pass unchanged.                                |
