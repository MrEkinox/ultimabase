An operation has two identities: what the caller requested and how the
database fulfills it. Keeping them separate lets a narrowly privileged plugin
change storage behavior without changing authorization or business semantics.

## Logical meaning versus physical statement

The logical operation records the command, schema, target, and caller input.
Policy, Hooks, audit, results, and relationship behavior use that identity.
The persistence plan describes the adapter statement. Core validates the plan
before the database plugin executes it.

For native commands, the current plan protocol permits identity execution and
only `delete-one` to `update-one` or `delete-many` to `update-many` rewrites.
Plugin-owned schema mutations can have their own logical identity while Core
compiles an approved update or delete statement. None of these paths is a
general SQL or arbitrary-operation rewrite API. A rewriter needs the exact
`persistence:rewrite` privilege, and an incompatible adapter rejects the plan.

With the optional Soft Delete plugin in `replace-delete` mode, `deleteOne` is
still a logical delete. The database writes a tombstone update, but update
policy, update Hooks, defaults, and generators do not run as if the caller had
requested `updateOne`. The returned delete result and transaction semantics
stay those of a delete. By contrast, the plugin's `explicit` mode adds a
separate logical `softDelete` command; it does not reinterpret native delete.

## Protected constraints stay outside the rewrite

Row filters and adapter constraints accumulated by policy do not enter the
replaceable plan. Core carries them beside it and the adapter combines every
constraint with `AND`. A persistence rewrite therefore cannot drop an ACL
filter, bypass tenant-like restrictions, or turn a denied target into a visible
one. The final physical write remains subject to those restrictions in the
same transaction.

Transports remain outside both layers: REST and GraphQL normalize requests and
serialize results, but never issue SQL or receive a raw adapter.
