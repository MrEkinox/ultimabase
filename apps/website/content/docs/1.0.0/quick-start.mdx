<Callout type="warn" title="Automatic setup is not yet available">
	The `@ultimabase/create-app` initializer has not been published. The command
	below shows the intended release experience; it will not set up an UltimaBase
	application today. To build one now, follow [Manual
	Installation](/docs/1.0.0/manual-installation).
</Callout>

## Context

The goal of Quick Start is to remove manual project setup when UltimaBase is
released. You will still need Node.js 24 or newer and a disposable PostgreSQL
database for the first application.

## Mental model

The intended entry point is a package-manager command. It will
initialize a project that you can inspect and edit, rather than changing how
UltimaBase schemas, plugins, or Runtime work. The planned flow asks for
TypeScript or JavaScript, REST and GraphQL HTTP APIs, official plugins, a Task
example or empty application, and a PostgreSQL setup. TypeScript includes
Typegen automatically; JavaScript does not.

The local, unpublished implementation already supports the PostgreSQL base
project plus Hooks, Validation, Soft Delete, PostgreSQL Vector, Password Auth,
Access, Roles, Object ACLs, REST, GraphQL, HTTP, Hono, GraphiQL, and Apollo
Sandbox selections. The Vector choice does not add persisted vector storage
or search. Security choices configure local Master auditing, but identity and
role membership alone do not grant data access. Generated Task API routes are
read-only by default; Password Auth operations are included only in an exact
selected transport allowlist. The managed server binds to loopback, and
explorers with introspection are development-only. This is a local setup
template, not a reviewed public deployment policy.

### Automatic installation

These are the proposed package-manager entry points, not runnable setup
instructions yet:

```bash tab="npm" tab-group="package-manager"
npm create @ultimabase/app@latest
```

```bash tab="yarn" tab-group="package-manager"
yarn dlx @ultimabase/create-app@latest
```

```bash tab="pnpm" tab-group="package-manager"
pnpm dlx @ultimabase/create-app@latest
```

## Boundaries

Do not assume an application has been generated or follow an unpublished
initializer in production automation. The manual path documents the actual
schema, PostgreSQL configuration, TypeScript setup, and lifecycle in full.
