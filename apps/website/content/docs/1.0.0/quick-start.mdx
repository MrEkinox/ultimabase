<Callout type="warn" title="Automatic setup is not yet available">
	The `create-ultimabase-app` initializer has not been published. The commands
	below show the intended release experience; they will not set up an UltimaBase
	application today. To build one now, follow [Manual
	Installation](/docs/1.0.0/manual-installation).
</Callout>

## Context

The goal of Quick Start is to remove manual project setup when UltimaBase is
released. You will still need a supported Node.js installation and a
PostgreSQL database for the first application.

## Mental model

The intended entry point is a package-manager `create` command. It will
initialize a project that you can inspect and edit, rather than changing how
UltimaBase schemas, plugins, or Runtime work. The generator's prompts, output
files, and supported options are not defined yet.

### Automatic installation

These commands are a preview of the intended package name, not runnable setup
instructions yet:

```bash tab="npm" tab-group="package-manager"
npm create ultimabase-app@latest
```

```bash tab="yarn"
yarn create ultimabase-app
```

```bash tab="pnpm"
pnpm create ultimabase-app
```

## Boundaries

Do not assume an application has been generated or follow an unpublished
initializer in production automation. The manual path documents the actual
schema, PostgreSQL configuration, TypeScript setup, and lifecycle in full.
