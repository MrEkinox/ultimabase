UltimaBase already has schemas, typed data operations, PostgreSQL, and optional
REST, GraphQL, and password authentication in the repository. See
[Release Status](./release-status) for what you can evaluate today. The cards
below show proposed product directions after the simplification work.

<Callout type="info" title="Simplification before new features">
	The simplification passes preserve current application behavior and used
	plugin contracts. Explicit decisions removed unused Runtime stage
	contributions, the Typegen emitter marker, and migration-only scaffolding.
	Hooks, generated types, and direct PostgreSQL synchronization remain
	supported. Files and caching remain planned and still need design work.
</Callout>

## Further ahead

These are separate proposed directions, not a delivery sequence. Some depend
on earlier work or still need design review.

### Application capabilities

<Cards>
	<Card
		title="Tenant isolation"
		description="Keep each tenant's data within its own request boundary."
		icon={<Shield />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/ROADMAP.md#tenant-isolation"
	>
		A proposed plugin would add typed tenant context and isolation filters that
		compose with Access, ACL, and relations.
	</Card>
	<Card
		title="Realtime"
		description="Post-commit events and a local adapter for development."
		icon={<Radio />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/ROADMAP.md#realtime"
	>
		First define safe events and subscription boundaries, then an isolated
		in-memory adapter.
	</Card>
	<Card
		title="Background jobs"
		description="Asynchronous work through an optional BullMQ plugin."
		icon={<ListTodo />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/ROADMAP.md#background-jobs"
	>
		Job handlers retain explicit request authority, with retry and idempotency
		metadata.
	</Card>
	<Card
		title="Reliable event delivery"
		description="Record event intent alongside business transactions."
		icon={<Send />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/ROADMAP.md#reliable-event-delivery"
	>
		A planned PostgreSQL outbox would support post-commit delivery with
		at-least-once semantics.
	</Card>
	<Card
		title="More authentication"
		description="An optional Better Auth integration."
		icon={<KeyRound />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/ROADMAP.md#more-authentication"
	>
		Separate from the existing Password Auth plugin, using shared HTTP and
		application capabilities.
	</Card>
</Cards>

## Planned is not shipped

The directions above do not establish a release date, implementation order,
or final API. There is no announced next-release feature list. Work may change
scope or be deferred after dependency and design review.

The [roadmap](https://github.com/MrEkinox/ultimadatabase/blob/main/ROADMAP.md)
carries the engineering context of each direction. To suggest a change or help
with one, see [Contributing](./contributing).
