This page covers possible future capabilities. For what exists in the
repository today, see [Release Status](./release-status) and the owning Core or
plugin documentation.

## Planned capabilities

The linked issues are **planned**, not implemented or scheduled. Each issue
defines a narrower scope and dependencies than this overview can show.

- **Realtime:** Define post-commit events and an optional local adapter.
  Tracked by the [event contract](https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/708-realtime-contract.md)
  and [memory adapter](https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/709-realtime-memory-adapter.md) issues.
- **Background jobs:** Run asynchronous work through an optional
  [BullMQ plugin](https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/712-bullmq-jobs.md).
- **Caching:** Cache query results without bypassing access rules or serving
  stale private data. Tracked by [cache contracts and invalidation](https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/713-cache-plugin.md).
- **API tooling:** Generate an [OpenAPI description](https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/715-openapi-generator.md)
  and a [TypeScript SDK](https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/719-typescript-sdk.md)
  through separate work.
- **Authentication:** Offer [Better Auth](https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/707-better-auth-plugin.md)
  as an optional integration.
- **Administration:** Provide a separately deployed
  [admin application](https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/727-admin-app.md)
  using public APIs and explicit Master authority.

## Planned is not shipped

These issues do not establish a release date, implementation order, or final
API. Work may change scope or be deferred after dependency and design review.
There is no announced next-release feature list. Do not base an application on
a planned capability until its owning documentation describes shipped behavior.

The [milestone plan](https://github.com/MrEkinox/ultimadatabase/blob/main/ROADMAP.md)
and [issue backlog](https://github.com/MrEkinox/ultimadatabase/tree/main/issues)
carry the complete engineering context. To suggest a change or help with an
existing issue, see [Contributing](./contributing).
