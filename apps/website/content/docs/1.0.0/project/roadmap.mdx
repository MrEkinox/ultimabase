UltimaBase already has schemas, typed data operations, PostgreSQL, and optional
REST, GraphQL, and password authentication in the repository. See
[Release Status](./release-status) for what you can evaluate today. The cards
below show what comes next and the later directions tracked in the issue backlog.

<Callout type="info" title="Current focus">
	Files and caching are the next two priorities. Both need design work before
	implementation begins; the linked issues are still marked planned.
</Callout>

## Next priorities

## Further ahead

These are separate issue-tracked directions, not a delivery sequence. Some
depend on earlier work or still need design review.

### Application capabilities

<Cards>
	<Card
		title="Tenant isolation"
		description="Keep each tenant's data within its own request boundary."
		icon={<Shield />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/724-multi-tenant-plugin.md"
	>
		A proposed plugin would add typed tenant context and isolation filters that
		compose with Access, ACL, and relations.
	</Card>
	<Card
		title="Realtime"
		description="Post-commit events and a local adapter for development."
		icon={<Radio />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/708-realtime-contract.md"
	>
		First define safe events and subscription boundaries, then an isolated
		in-memory adapter.
	</Card>
	<Card
		title="Background jobs"
		description="Asynchronous work through an optional BullMQ plugin."
		icon={<ListTodo />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/712-bullmq-jobs.md"
	>
		Job handlers retain explicit request authority, with retry and idempotency
		metadata.
	</Card>
	<Card
		title="Reliable event delivery"
		description="Record event intent alongside business transactions."
		icon={<Send />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/711-postgres-outbox.md"
	>
		A planned PostgreSQL outbox would support post-commit delivery with
		at-least-once semantics.
	</Card>
	<Card
		title="More authentication"
		description="An optional Better Auth integration."
		icon={<KeyRound />}
		href="https://github.com/MrEkinox/ultimadatabase/blob/main/issues/700-extensions/707-better-auth-plugin.md"
	>
		Separate from the existing Password Auth plugin, using shared HTTP and
		application capabilities.
	</Card>
</Cards>

## Planned is not shipped

The issues above do not establish a release date, implementation order, or
final API. There is no announced next-release feature list. Work may change
scope or be deferred after dependency and design review.

The [milestone plan](https://github.com/MrEkinox/ultimadatabase/blob/main/ROADMAP.md)
and [issue backlog](https://github.com/MrEkinox/ultimadatabase/tree/main/issues)
carry the full engineering context. To suggest a change or help with an issue,
see [Contributing](./contributing).
