## Prerequisites

Complete [Manual Installation](/docs/1.0.0/manual-installation) and understand
[Application](/docs/1.0.0/core/application#start-and-dispose).

## Shortest path

From the repository root, verify the maintained complete example without secrets or
a running database:

```sh
corepack yarn workspace @ultimabase/example-minimal check-generated-types
corepack yarn workspace @ultimabase/example-minimal typecheck
```

Use Vitest for behavior. Create a fresh application per test, use a deterministic
public adapter fake for narrow Runtime tests, and reserve PostgreSQL Testcontainers
for adapter integration behavior.

## Verify the outcome

Assert generated declarations are unchanged, public exports compile, startup and
disposal complete, and observable results match. For plugin packages, use
`definePluginConformanceSuite()` plus only the domain checks the plugin actually owns.

## Limitations

Type checks do not prove PostgreSQL or network behavior. Do not share applications,
pools, schemas, or mutable plugin instances between parallel workers.
