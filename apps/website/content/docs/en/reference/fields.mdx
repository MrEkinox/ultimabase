## Signature

```ts
fields: (field) => ({
	title: field.string({ required: true }),
	views: field.int({ default: 0 }),
	author: field.pointer({ target: 'Author' }),
	tags: field.relation({ target: 'Tag' }),
	summary: field.virtual({
		output: (output) => output.string({ nullable: false }),
		select: { title: true },
		resolve: ({ item }) => item.title,
	}),
})
```

## Parameters

| Method family                       | Logical value                 | Important options                                                   |
| ----------------------------------- | ----------------------------- | ------------------------------------------------------------------- |
| `string`, `boolean`, `int`, `float` | primitive                     | `required`, `default`, `immutable`, `list`, `indexed`               |
| `bigint`, `decimal`                 | canonical string              | decimal `precision` and `scale`                                     |
| `date`, `dateTime`, `time`          | canonical temporal string     | temporal generation where supported                                 |
| `uuid`, `binary`, `json`            | UUID, bytes, or portable JSON | scalar-common options                                               |
| `enum`                              | declared string union         | required `values`, optional `typeName`                              |
| `object`                            | typed embedded object         | restricted embedded `fields` callback                               |
| `pointer`                           | one target identity           | `target`, `onDelete`, `required`, `indexed`                         |
| `relation`                          | to-many handle                | `target`, optional `mappedBy` and contextual `where`                |
| `virtual`                           | output-only value             | `output`, persisted `select`, synchronous or asynchronous `resolve` |

Installed plugins may add a method only to declared contexts: `stored`,
`embedded`, `virtual`, or `output`. A portable codec does not imply support in
every context.

## Defaults

Stored fields are optional unless `required: true`. `onDelete` defaults to
`restrict`. Relations are never nullable and never appear in mutation scalar
data. Virtual fields are selected result fields but are not stored, indexed,
filterable, orderable, or writable.

## Returns

Every method returns an immutable declaration. Stored and embedded declarations
contribute to canonical mutation values; pointers return `Pointer` values;
relations become `Relation` handles on persisted models; virtual fields return
their declared output shape.

## Errors

Unsupported option combinations fail at declaration or application compilation.
Runtime rejects unknown input fields, invalid scalar shapes, unavailable plugin
methods, unresolved targets, and virtual output that violates its descriptor.

## Example

```ts
const Event = Schema.define({
	className: 'Event',
	fields: (field) => ({
		startsAt: field.dateTime({ required: true }),
		metadata: field.object({
			fields: (embedded) => ({ source: embedded.string() }),
		}),
	}),
})
```
