UltimaBase targets Node.js 24+, ESM, and TypeScript. This repository pins Yarn
4.9.2; applications may use their package manager while keeping published package
versions aligned. The integration suite currently verifies PostgreSQL 17.

Treat `process.env` as untrusted input. Read, validate, and convert values at the
composition root, then pass typed options to plugin factories.

```ts fixture="operations/configuration.ts"
import { UltimaBase } from '@ultimabase/core'
import { httpPlugin } from '@ultimabase/http-plugin'
import { postgresPlugin } from '@ultimabase/postgres-plugin'

const databaseUrl = process.env.DATABASE_URL
if (databaseUrl === undefined) throw new TypeError('DATABASE_URL is required')

export const application = new UltimaBase({
	plugins: [
		postgresPlugin({ schemaPolicy: 'fail', url: databaseUrl }),
		httpPlugin({ appId: process.env.ULTIMABASE_APP_ID ?? 'api' }),
	],
	schemas: [],
})
```

Plugin configuration is application-local. Separate applications do not share
schemas, contexts, capabilities, connections, or lifecycle unless one exact provider
value is deliberately reused according to its public contract.
