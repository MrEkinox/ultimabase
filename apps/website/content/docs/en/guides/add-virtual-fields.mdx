## Prerequisites

Understand [Selections](/docs/querying/selections) and ordinary
[Fields](/docs/data-modeling/fields).

## Shortest path

```ts
displayTitle: field.virtual({
	output: (output) => output.string({ nullable: false }),
	select: { title: true },
	resolve: ({ item }) => String(item.title).toUpperCase(),
})
```

Core authorizes the virtual field, loads `title` privately, validates the resolved
output, and exposes only the requested result.

## Verify the outcome

Select only `id` and `displayTitle`; confirm `title` is absent from the returned
model. Select the same field through REST and GraphQL and compare its value.

## Limitations

Virtual fields are unavailable in mutation data, filters, ordering, indexes, and
storage. Their resolver must return the declared output shape.
