## Prerequisites

Read [Contextual Relations](/docs/querying/contextual-relations) and
[Request Identity](/docs/security/request-identity).

## Shortest path

```ts
reviewers: field.relation({
	target: 'User',
	where: ({ context, where }) =>
		context.getValue(passwordPrincipal) === undefined
			? where.eq('audience', 'public')
			: where,
})
```

## Verify the outcome

Compare anonymous and authenticated relation handles, eager includes, REST
projections, GraphQL connections, counts, and predicates. Each must use the same
visible relation universe before pagination.

## Limitations

The resolver is synchronous, request-local, and receives no source item or adapter.
It shapes only this traversal and is not authorization; protect targets independently.
