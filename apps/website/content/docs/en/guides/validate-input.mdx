## Prerequisites

Complete [Define Schemas](/docs/data-modeling/schemas) and install a Standard
Schema implementation such as Zod. Add `validationPlugin()` explicitly.

## Shortest path

```ts
title: field.string({
	required: true,
	validation: z.string().min(1).max(200),
})
```

Core still owns requiredness, nullability, and structural types. The Validation
plugin adds a synchronous rejection-only check over the final resolved value.

## Verify the outcome

Submit an empty title and assert the stable `field.validation` issue path. Submit a
valid title and read it back. Master must receive the same validation result.

## Limitations

Validators cannot transform values, return promises, or run on reads. Use
[Hooks](./run-lifecycle-hooks) for deliberate input normalization.
