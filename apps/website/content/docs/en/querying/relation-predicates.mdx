Relation predicates decide whether a source record matches without loading the
related collection into application code.

```ts title="src/relation-filters.ts"
import { Author, Post } from './schemas.js'
import { ultimabase } from './ultimabase.js'

export const readEstablishedAuthors = () =>
	Author.findMany(
		{
			where: {
				posts: {
					count: {
						gte: 3,
						where: { published: { eq: true } },
					},
					some: { score: { gte: 80 } },
				},
			},
		},
		{ ultimabase },
	)

export const readPostsWithoutComments = () =>
	Post.findMany({ where: { comments: { isEmpty: true } } }, { ultimabase })
```

## Quantifiers

| Predicate      | Matches when                                |
| -------------- | ------------------------------------------- |
| `some: where`  | At least one visible target matches `where` |
| `none: where`  | No visible target matches `where`           |
| `every: where` | No visible target violates `where`          |

`every` is true for an empty visible relation. Combine predicates when your
domain also requires at least one target.

## Emptiness

`isEmpty: true` is the readable form of `none: {}`. `isNotEmpty: true` is the
readable form of `some: {}`. The flags accept only literal `true` and use
existence semantics rather than aggregate counts.

## Cardinality

`count` supports `eq`, `ne`, `gt`, `gte`, `lt`, `lte`, `in`, `notIn`,
`between`, and `notBetween` with non-negative safe integers. At least one
comparison is required. Its optional target `where` narrows the related targets
before every comparison is evaluated.

The first example requires at least three visible published posts and at least
one visible high-scoring post. Those conditions may be satisfied by different
members because sibling predicates combine through `AND` independently.

All predicates observe the same visible relation universe: physical membership,
the field's declared relation filter, target policy and protected constraints,
then the caller's target predicate. Hidden targets are not counted and cannot
satisfy quantifiers.
