## Prerequisites

Define [Relationships](/docs/1.0/core/data-modeling/relationships), then read the canonical
[Nested Writes](/docs/1.0/core/writing-data/nested-writes) contract.

## Shortest path

```ts
await Article.createOne({
	data: {
		author: { connect: authorId },
		contributors: { create: [{ name: 'Grace' }] },
		title: 'Nested writes',
	},
	include: { contributors: { select: { name: true } } },
})
```

## Verify the outcome

Read the article and contributor after success. Force one child validation failure
and confirm neither the root, child, nor relation membership persists.

## Limitations

Nested commands are available only on singular create and update. Nested delete and
upsert are not available; depth and operation budgets are application-wide.
