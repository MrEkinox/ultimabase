## Prerequisites

Read [Transactions](/docs/1.0/mutations/transactions) and install `hooksPlugin()`.

## Shortest path

Use field `resolveInput` to return the normalized value. Use schema
`beforeOperation.create` for business work that must commit or roll back with the
primary mutation.

```ts
title: field.string({
	hooks: { resolveInput: ({ value }) => value?.trim() ?? null },
})
```

## Verify the outcome

Create a title with surrounding whitespace and assert the stored result is trimmed.
Then make a later Hook fail and verify both the primary row and audit row roll back.

## Limitations

Hooks do not replace operation input, results, or persistence plans. `afterOperation`
still runs before commit; use emitted events for post-commit delivery.
