Use `Schema.createOne` for a single root mutation. Its input is checked against
the generated schema surface, and `select` plus `include` determine both the
returned data and its TypeScript type.

```ts title="src/create-post.ts"
import { Post } from './schemas.js'
import { ultimabase } from './ultimabase.js'

export const createPost = (authorId: string) =>
	Post.createOne(
		{
			data: {
				author: { connect: authorId },
				slug: 'first-post',
				title: 'First post',
			},
			include: { author: { select: { displayName: true } } },
			select: { slug: true, title: true },
		},
		{ ultimabase },
	)
```

Core applies generated values and defaults once, runs structural validation,
the configured policy and Hook capabilities, then persists the record in one
automatic transaction. The returned model is immutable: changing data means
issuing another command, not assigning a property.

Use `Schema.create(data)` when you need an immutable draft before persistence,
then call `draft.create()`. Drafts are useful for local composition, but nested
writes belong to `createOne` and are not available on draft creation.

Continue with [Update Records](./update), or learn how one root write can own a
bounded graph in [Nested Writes](./nested-writes).
