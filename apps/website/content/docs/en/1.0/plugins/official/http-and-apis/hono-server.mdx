`@ultimabase/server-hono-plugin` is the optional Node.js server provider. It
consumes the shared [HTTP plugin](./http) capability; it does not install REST,
GraphQL, authentication, TLS, proxy trust, compression, or rate limiting.

```ts
import { honoServerPlugin } from '@ultimabase/server-hono-plugin'

const server = honoServerPlugin({ host: '127.0.0.1', port: 1337 })
```

Without an existing Hono application, the plugin creates the listener during
the transport start phase and closes it after the last attached UltimaBase
application stops. Reuse the same `server` value to share one listener; separate
factory calls create independent providers.

Pass `app` to join a developer-owned Hono assembly. In that mode UltimaBase adds
its dispatcher but never starts or stops the application or listener. The
configuration must also name whether UltimaBase or existing middleware owns the
browser policy, so contradictory CORS headers fail instead of being merged.
