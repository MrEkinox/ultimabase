## Overview

`@ultimabase/hooks-plugin` supplies UltimaBase's official field and schema Hooks.
Importing the package installs nothing, and an application without
`hooksPlugin()` has no neutral or hidden Hook stages.

## Installation and configuration

Install the plugin and add `hooksPlugin()` to the application graph. Use field
`resolveInput` to normalize a value:

```ts
title: field.string({
	hooks: { resolveInput: ({ value }) => value?.trim() ?? null },
})
```

Use schema `beforeOperation.create` for business work that must commit or roll
back with the primary mutation.

## Runtime order and transactions

Field `resolveInput` Hooks normalize values. Schema and application observers
perform ordered work around the logical mutation. Business after-Hooks still
run before commit and may abort the transaction; external delivery belongs
after commit.

## Verify and troubleshoot

Create a title with surrounding whitespace and verify the stored result is
trimmed. Then make a later Hook fail and confirm that both the primary row and
transaction-bound work roll back.

Hook order follows plugin dependencies, plugin position, and registration order.
Hooks never replace authorization, structural validation, persistence plans, or
transaction ownership. `afterOperation` still runs before commit; use emitted
events for post-commit delivery.
