`@ultimabase/apollo-sandbox-plugin` contributes a browser explorer only. It does
not install GraphQL, Yoga, HTTP, or a server.

```ts
import { apolloSandboxPlugin } from '@ultimabase/apollo-sandbox-plugin'

const explorer = apolloSandboxPlugin({ environment: 'development' })
```

For application ID `notes`, open
`/__ultimabase/apps/notes/apollo-sandbox`. The page fixes the installed GraphQL
HTTP endpoint, attaches the public application ID, and disables endpoint editing
and cookie controls. It embeds no credential or authority.

Production contributes no route unless `allowInProduction: true` is explicit.
Schema discovery also requires GraphQL HTTP introspection. The Apollo CDN asset
is visible in the plugin's network environmental claim.
