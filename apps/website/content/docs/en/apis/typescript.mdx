The TypeScript API is the shortest path into an UltimaBase application. Schema-root
commands normalize into the shared Runtime, where validation, Access, ACL, Hooks,
transactions, protected constraints, and result materialization run in the same
order used by REST and GraphQL.

```ts fixture="apis/typescript.ts"
import { ApiPost } from './schema.js'

export const readPublishedPosts = () =>
	ApiPost.findMany({
		limit: 20,
		select: { id: true, title: true },
		where: { published: { eq: true } },
	})
```

Persisted immutable models add item commands such as `update()` and `delete()`.
They delegate back through Query and Runtime; they are not mutable Active Record
objects and never receive a raw adapter.

```text
Schema.findMany / model.update
             ↓
      logical operation
             ↓
  shared Runtime pipeline
             ↓
       database plugin
```

Direct code may supply an application, an existing request context, or the trusted
server-only Master option. The terminal accepts no public engine, adapter, grant,
or lifecycle mutation facade.

Next, add the [HTTP application boundary](./http-applications), expose selected
[REST](./rest) routes, or generate a network-independent [GraphQL](./graphql)
schema. Exposure is never authorization; review [application security](../security/overview)
before serving public traffic.
