## Symptom

The generated declaration is missing or stale, TypeScript cannot see a schema or
plugin-owned field, or generation throws `SCHEMA_TYPEGEN_FAILED`. Its stable
`reason` is one of `invalid-application-export`, `unsupported-field-kind`,
`malformed-plugin-contribution`, `generated-identity-conflict`, or
`output-path-conflict`.

## Cause

Typegen loads one named `UltimaBase` or `FrameworkApplication` export, compiles
the static application graph, and atomically replaces an inert `.d.ts` file.
Failures therefore come from the selected source/export, an incomplete field or
plugin Typegen contribution, conflicting generated identities, or two emitters
claiming one output path. Generated files never control Runtime behavior.

## Confirm

Run the application's normal generation or startup command, then TypeScript:

```sh
yarn dev
yarn typecheck
```

Check that `.ultimabase/schema.generated.d.ts` starts with the generated-file
notice and contains an `@ultimabase/schema-fingerprint`. Compare it with version
control rather than editing it:

```sh
git diff -- .ultimabase/schema.generated.d.ts
```

Capture the error `code`, `reason`, `owner`, and sanitized relative `path`.
Do not include source contents or environment values in a public report.

## Resolve

- Export the configured application name from the configured source module.
- Register a public Typegen reference and deterministic declaration for each
  custom field or plugin surface.
- Give independent applications distinct `applicationId` values and output
  paths.
- Remove hand edits and regenerate the complete file from the current graph.
- Keep generated declarations included by `tsconfig.json`; do not make them a
  Runtime import.

<Callout title="Host-specific filesystem failures">
	Permissions, path casing, and filesystem sandbox restrictions vary by host.
	Verify the configured path with that platform's normal tools and grant access
	only to the generated directory; do not loosen repository-wide permissions.
</Callout>

## Escalate

Provide a minimal exported application, the Typegen options, the stable failure
reason, and the declaration diff if it contains no private names. Include Node,
package-manager, TypeScript, and UltimaBase versions. Continue with
[Reporting a problem](./reporting-a-problem).
