## Prerequisites

Configure [Password Authentication](/docs/1.0/plugins/official/authentication-and-authorization/password-authentication),
[Access](/docs/1.0/plugins/official/authentication-and-authorization/access), the [HTTP application](/docs/1.0/plugins/official/http-and-apis/http),
and [REST](/docs/1.0/plugins/official/http-and-apis/rest). Keep `ULTIMABASE_MASTER_KEY` server-side.

## Shortest path

List the four `passwordAuthOperations` explicitly in `restPlugin({ operations })`.
Call the login operation, then send exactly one returned session token:

```http
Authorization: Bearer ub_s1.REDACTED_SESSION_TOKEN
X-UltimaBase-Application-Id: minimal
```

## Verify the outcome

Assert an anonymous protected read is denied, the Bearer request succeeds, and a
revoked or foreign-application token fails before route dispatch.

## Limitations

Authentication establishes identity and grants no authorization. V1 has no password
recovery, MFA, rate limiter, device list, or logout-all operation.
