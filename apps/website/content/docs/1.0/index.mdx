UltimaBase is an open-source, Node.js-first framework for building typed data
applications from static TypeScript schemas. You declare the data model and
choose explicit plugins; UltimaBase compiles that graph and sends every
operation through one Runtime pipeline.

<Callout title="Pre-release contract">
	UltimaBase is under active development before its first stable release. The
	documentation describes behavior that exists today, but public APIs may still
	change deliberately.
</Callout>

## Context

Application developers can start with a small TypeScript project without
choosing an HTTP transport. Plugin authors extend the same application graph,
and operators can follow its explicit configuration and lifecycle. No prior
UltimaBase knowledge is required.

## Mental model

Your schema and the plugins you install form one compiled application graph.
Core owns the schema, immutable data commands, structural validation, and the
Runtime pipeline. The PostgreSQL plugin supplies persistence. Generated types
can improve editor support later, but they are not executable application code.

## Boundaries

UltimaBase is not a hosted backend service or a Parse Server-compatible clone.
Application code does not write Drizzle queries directly. Authentication,
authorization, HTTP, REST, and GraphQL are optional capabilities; Core does
not install them for you.
