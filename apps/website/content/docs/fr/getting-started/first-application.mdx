## Ce que vous allez construire

L’application possède un schéma statique `Task` et un plugin PostgreSQL. Au
démarrage, UltimaBase compile exactement ce graphe, prépare la structure,
connecte le Runtime et rend la commande du schéma disponible.

## Prérequis

Terminez [l’installation](./installation) et vérifiez que la base désignée par
`DATABASE_URL` est accessible. Le code utilise des imports ESM : les imports
TypeScript locaux se terminent donc par `.js`. Le compilateur les résout vers
leurs sources `.ts` et produit des chemins valides pour Node.js.

## Étapes

Définissez le modèle de données. Les factories de champs préservent la forme
TypeScript exacte, et Core valide la même structure au Runtime.

```ts title="src/schema.ts"
import { Schema } from '@ultimabase/core'

export const Task = Schema.define({
	className: 'Task',
	fields: (field) => ({
		done: field.boolean({ default: false }),
		title: field.string({ required: true }),
	}),
})
```

Créez l’application. `schemaPolicy: 'override'` est pratique pour cette base
jetable : la stratégie crée les structures manquantes et applique les changements
pris en charge, mais ne remplace pas des migrations de production relues.

```ts title="src/ultimabase.ts"
import { UltimaBase } from '@ultimabase/core'
import { postgresPlugin } from '@ultimabase/postgres-plugin'

import { Task } from './schema.js'

const databaseUrl = process.env.DATABASE_URL

if (databaseUrl === undefined) {
	throw new TypeError('DATABASE_URL is required')
}

export const ultimabase = new UltimaBase({
	plugins: [
		postgresPlugin({
			schemaPolicy: 'override',
			url: databaseUrl,
		}),
	],
	schemas: [Task],
})
```

Démarrez l’application, créez un enregistrement par le Runtime partagé et
libérez toujours les ressources :

```ts title="src/main.ts"
import { Task } from './schema.js'
import { ultimabase } from './ultimabase.js'

try {
	await ultimabase.start()

	const task = await Task.createOne(
		{ data: { title: 'Write the documentation' } },
		{ ultimabase },
	)

	process.stdout.write(`${JSON.stringify(task.toJSON())}\n`)
} finally {
	await ultimabase.dispose()
}
```

Exécutez la vérification locale complète :

```bash title="Terminal"
npm run typecheck
npm run build
npm start
```

## Résultat attendu

Le processus affiche un objet JSON contenant un `id` généré, le titre
`"Write the documentation"` et `done: false`, puis s’arrête après avoir fermé le
pool PostgreSQL possédé par l’application. UltimaBase a aussi préparé la
structure gérée correspondant au schéma `Task`.

Si le démarrage échoue, vérifiez d’abord que `DATABASE_URL` est chargé et que la
base accepte une connexion depuis le même terminal.
