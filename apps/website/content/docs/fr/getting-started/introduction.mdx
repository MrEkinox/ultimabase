UltimaBase est un framework open source pensé d’abord pour Node.js. Il permet de
construire des applications de données typées à partir de schémas TypeScript
statiques. Vous déclarez le modèle de données et choisissez des plugins
explicites ; UltimaBase compile ce graphe et fait passer chaque opération par un
seul pipeline Runtime.

<Callout title="Contrat de préversion">
	UltimaBase évolue activement vers sa première version stable. La documentation
	décrit les comportements disponibles aujourd’hui, mais les API publiques
	peuvent encore changer de manière volontaire.
</Callout>

## Ce que vous allez construire

Ce parcours crée un schéma `Task`, le connecte à PostgreSQL, démarre
l’application, écrit un enregistrement puis ferme la connexion possédée par
l’application. Il utilise uniquement TypeScript en direct afin que les sujets
liés aux transports ne masquent pas le premier résultat fonctionnel.

À la fin, vous aurez vu le contrat central :

**Un seul parcours d’application compilé**

Le schéma et les plugins choisis deviennent la vérité du Runtime de
l’application.

## Prérequis

Vous devez savoir créer un petit projet TypeScript et définir une variable
d’environnement. Il vous faut Node.js 24 ou plus récent et une base PostgreSQL
que vous pouvez utiliser sans risque pour le développement.

Aucune connaissance préalable d’UltimaBase n’est nécessaire. Continuez avec
[l’installation](./installation).

## Étapes

UltimaBase conserve volontairement les comportements concrets sous forme de
capacités optionnelles :

1. Core possède les schémas, le graphe d’application, les API immuables de
   requête et de mutation, la validation structurelle, les transactions et le
   pipeline Runtime partagé.
2. Les plugins ajoutent des capacités concrètes comme PostgreSQL, la validation,
   les règles d’accès, l’authentification, REST ou GraphQL.
3. Votre graphe configuré — et non le code généré — est la vérité de
   l’application au Runtime.

Cette séparation permet à une petite application de n’installer que ce qu’elle
utilise. Elle rend aussi visibles dans le code les frontières d’infrastructure,
de sécurité et de transport.

## Résultat attendu

UltimaBase est pertinent si vous cherchez une application de données TypeScript
typée, PostgreSQL comme voie de persistance principale, des builders immuables
et une composition explicite plutôt qu’un serveur tout-en-un caché.

Ce n’est ni un service backend hébergé, ni un clone compatible de Parse Server,
ni un moyen d’écrire directement des requêtes Drizzle dans le code applicatif.
Core n’installe pas silencieusement l’authentification, l’autorisation, HTTP,
REST, GraphQL ou l’infrastructure opérationnelle.
