A json schema with an id and `scalar: true`, `.meta({ id: 'RichText', scalar: true })`, is the GraphQL scalar `RichText`, read and written whole, in a json field or a function. The id is also read from an `id` keyword, as Valibot and ArkType write it, which names a shared object type too.
