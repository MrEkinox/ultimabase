# @ultimabase/graphql-http

The provider-neutral contract of one application GraphQL HTTP endpoint, shared
by GraphQL HTTP adapters and browser tools. It is not a plugin and installs no
behavior.

## Installation

```sh
npm install @ultimabase/graphql-http @ultimabase/core
```

`@ultimabase/core` is a peer dependency. Applications rarely import it; plugin
authors do.
