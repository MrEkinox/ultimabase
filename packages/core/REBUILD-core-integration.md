# Core rebuild: integration pass

Reference snapshot: `0ae7767f7b75dd6c640ca547f9ff85b60f46e69d`.

Scope: all of `packages/core/src`, after the five partitions (`core-schema`,
`core-plugins`, `core-query`, `core-runtime-pipeline`, `core-runtime-app`) were
merged. The frozen partition interfaces
(`docs/rebuild/core-interfaces/iface-*.txt`) are retired: cross-partition
module paths and internal symbols may now change, provided every Core consumer
is updated. Core's public contract (`src/index.ts` exports, signatures,
generics, JSDoc, `package.json` exports) is unchanged.

Status: work in progress (see the commits on `rebuild/core-integration`).
