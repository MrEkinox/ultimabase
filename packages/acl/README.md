# @ultimabase/acl

Per-row rights for UltimaBase. Each row stores who reads it and who writes it: by user, by role, or for the public. A query sees only the rows its caller may read, and writes only those it may write.

Documentation: [ACL](https://github.com/MrEkinox/ultimadatabase/blob/main/website/content/docs/acl.mdx).
