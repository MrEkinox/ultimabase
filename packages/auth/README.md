# @ultimabase/auth

Authentication for UltimaBase. It declares the user model, keeps the sessions, and gives each request its caller: the user its session names. A sign-in plugin, as `@ultimabase/password`, adds the way to sign in.

Documentation: [Authentication](https://github.com/MrEkinox/ultimadatabase/blob/main/website/content/docs/auth.mdx).
