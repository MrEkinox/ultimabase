# @ultimabase/pg-vector-plugin

Plugin-owned vector fields: `pgVectorPlugin()` adds
`field.vector({ dimensions })` to stored schema fields. It is unfinished:
vectors have no PostgreSQL storage yet.

## Installation

```sh
npm install @ultimabase/pg-vector-plugin @ultimabase/core
```

`@ultimabase/core` is a peer dependency.
