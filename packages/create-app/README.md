# @ultimabase/create-app

The project initializer: it generates a PostgreSQL UltimaBase project in
TypeScript or JavaScript, with a runnable starter or an empty application, from
interactive prompts or flags.

## Installation

The package is not published yet. Once it is, start a project with one of:

```sh
npm create @ultimabase/app@latest
yarn dlx @ultimabase/create-app@latest
pnpm dlx @ultimabase/create-app@latest
```
