# @ultimabase/shared

Dependency-light primitives shared by the foundational packages: branded
identifiers, `MaybePromise`, shallow immutable collection helpers, exhaustive
checks and runtime guards. Most applications never import it directly.

## Installation

```sh
npm install @ultimabase/shared
```

It has no peer dependencies.
