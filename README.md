# UltimaBase

A TypeScript backend framework inspired by Parse Server, built around a small
plugin-agnostic kernel and a community plugin ecosystem.

> Status: restarting from a clean base. The design is being decided in
> [docs/decisions.md](docs/decisions.md) before any code is written. Nothing is
> published on npm.

The previous implementation is archived in Git tags: `codex-archive` holds its
last validated state, and the older `*-archive` tags hold its history.
