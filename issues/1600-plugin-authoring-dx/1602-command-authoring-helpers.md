# 1602: Compose schema and model command authoring

- Status: planned
- Milestone: 16
- Packages: `@ultimabase/plugin-kit`, `@ultimabase/core`, `@ultimabase/typegen`, `@ultimabase/testing`
- Depends on: 1509, 1604
- ADR: ADR-0192, ADR-0197, ADR-0198, ADR-0201

## Goal

Let a plugin author define and attach a schema or model command as one focused
feature instead of manually repeating operation tokens, providers, declarations,
surface aliases, and derivable Typegen metadata.

## Acceptance criteria

- [ ] Add focused `defineSchemaCommand` and `defineModelCommand` helpers, or a smaller equivalent API proven by the workflow and JavaScript fixtures.
- [ ] One definition composes the exact operation contract, handler provider, owner-scoped declaration, target selector, and direct application-local method alias.
- [ ] Operation name, alias, transaction policy, input, result, public error codes, target model state, and handler context retain exact inference and hover documentation.
- [ ] Generated command declarations are derived from the compiled graph; helpers add no executable Typegen output or generated Runtime client.
- [ ] Required privileges and reasons remain explicit in the plugin manifest and are enforced by Core before declarations or providers materialize.
- [ ] The low-level `defineOperation`, `providePluginOperation`, registrar, `.command(name)`, and operation-handle APIs remain available for dynamic or infrastructure code.
- [ ] Migrate the workflow proof and at least one official or milestone-15 consumer without changing Runtime behavior.

## Tests

- [ ] Runtime, type, language-service, source, packed, JavaScript, immutability, and application-isolation tests cover both schema and model commands.
- [ ] Negative tests cover wrong targets, duplicate aliases, field or built-in collisions, missing privileges, invalid results, disposal, and cross-application models.

## Out of scope

- Automatic transport exposure.
- Implicit privilege inference or privilege reasons generated by the helper.
- Mutable Active Record state or schema/prototype mutation.
