# 6316: Audit parity, DX, complexity, and TypeScript cost

- Status: planned
- Milestone: 63
- Packages: complete repository
- Depends on: 6315
- ADR: ADR-0279, ADR-0280, ADR-0281, ADR-0283
- Execution contract: [milestone 63 DX and audit contract](../../docs/plans/2026-09-28-source-typed-application-authoring-target.md)

## Goal

Prove with exact old-versus-new evidence that source-typed authoring improves
developer experience and reduces implementation debt without losing an
UltimaBase capability or making TypeScript impractical.

## Acceptance criteria

- [ ] The ADR-0259 capability matrix and every capability added afterward are reconciled against the final implementation.
- [ ] The audit compares complete old and new application, schema, plugin-author, command, and local-exception examples.
- [ ] Production, Core, plugin, test, documentation, public export, dependency, package, declaration-byte, and changed-file deltas are reported exactly.
- [ ] Removed Typegen plugin projections, retained Typegen graph code, and new Core/plugin source-typing code are measured separately so a facade cannot hide net complexity.
- [ ] Explicitly inventory the approved Password Auth User-result exception: generated declarations still needed for exact local fields on `User.findMany()` and authentication results, the developer cost of regenerating them, and whether a later Core model-reference type redesign could eliminate this dependency without a parallel registry or lost capability.
- [ ] Reconcile issue 6319's configured Password User form with standalone specialized authoring: distinguish source-owned builders/options from any retained generated contracts used by `RoleSchema.define(options)`, `PasswordUserSchema.define(options)`, or `Schema.defineSpecialized()`. Report the final 6313 classification without counting a configured overload as removal of those contracts.
- [ ] Explicitly inventory ADR-0283's ACL schema-option descriptor: exact `acl.default`/`acl.resolveInput` sibling fields depend on the retained Typegen graph, while option presence and Runtime behavior remain source-owned. Measure its generated bytes and regeneration DX without counting it as removed Typegen.
- [ ] Explicitly inventory every retained generated schema `WhereInput` under ADR-0281: built-in, plugin scalar, structural, pointer, and relation filters; declaration/code bytes and regeneration DX; the issue-6312 codec-presence proof and its exact failure; and later alternatives without a second registry or capability loss. Do not count this retention as Typegen removal or a proven TypeScript impossibility.
- [ ] Distinguish the locked issue-6301 synthetic hybrid benchmark from measured production Typegen: its reduced `createRegistry()` omits complete generated `WhereInput`, so its declaration-byte and regeneration advantage cannot stand in for the final retained graph.
- [ ] Compare nested plugin-option QuickInfo documentation in configured source and packed schemas against the generated baseline; issue 6310's `rest.count` proof found an exact type but no JSDoc in the configured path. The user accepted this limitation for the milestone, not as a permanent removal of hover explanations.
- [ ] Measure the packed `SchemaResult.update()` hover after issue 6318: an exact configured source schema expands its update-input internals and TypeScript abbreviates the result as `Promise<...>`, whereas the prior standalone broad-schema fixture displayed a compact `Promise<{ ... }>` result. Verify exactness and documentation separately, and present the hover-verbosity tradeoff rather than silently weakening the editor contract.
- [ ] Present every accepted or retained limitation separately to the user at the end of the milestone, including Typegen exceptions and the nested plugin-option hover documentation gap, before deciding whether or how to address each one.
- [ ] Typegen regeneration, complete edit-to-diagnostic latency, cold typecheck, language-service initialization, completion, hover, diagnostics, heap, Runtime startup, complete tests, and coverage are compared with raw samples and summarized distributions.
- [ ] Every locked issue-6301 budget passes; any exception requires explicit user approval and cannot be hidden by averaging unrelated fixtures.
- [ ] Total handwritten production lines are below 122,645, public exports are below 1,720, and aggregate package declaration bytes do not exceed 839,935.
- [ ] No second public or private Typegen replacement, duplicate plugin installation path, schema auto-registration, `Schema.use()`, or permanent application-handle bridge remains.
- [ ] Coverage percentages and counters do not regress without an explained unreachable-code removal that increases or preserves effective coverage.
- [ ] `yarn validate:full` passes and the complete results are recorded.
- [ ] The final report states what improved, what became worse, remaining debt, and whether the approved DX target was achieved honestly.
- [ ] The final report renders the complete final one-file developer form, with no temporary syntax, and compares every authoring concern with the saved canonical target.
- [ ] Documentation impact is recorded.
