# 3405: Audit behavior, documentation, and DX

- Status: planned
- Milestone: 34
- Depends on: 3404
- ADR: ADR-0270

## Goal

Prove repository-wide parity and report whether the contribution-first API
materially reduces plugin-authoring ceremony.

## Acceptance criteria

- [ ] Compiled graphs, privilege reports, capability inventories, lifecycle
      order, Typegen, transports, Runtime, and cleanup retain parity.
- [ ] Public and package documentation shows only the canonical API.
- [ ] Full validation and coverage pass without regression.
- [ ] Added/deleted lines, representative before/after forms, remaining
      complexity, and recommended follow-up work are recorded.
