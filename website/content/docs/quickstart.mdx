---
title: Quickstart
description: Create an application, run it, query it over GraphQL and test it.
---

You need Node 24.7 or later: Node runs the TypeScript as it is written, with no
build step.

## Create the application

```npm
npm create ultimabase@latest my-app
cd my-app
npm install
```

The starter prints the next commands for the manager that ran it: npm, pnpm
or yarn. It refuses a directory that is not empty, and a name npm cannot
use for a package.

## Run it

```npm
npm start
```

The application listens on `http://localhost:3000`, GraphQL on `/graphql`.
`PORT` sets another port. Create a post and list the posts:

```bash
curl http://localhost:3000/graphql -H 'content-type: application/json' \
  -d '{"query":"mutation { createPost(data: { title: \"Hello\" }) { id title } }"}'
curl http://localhost:3000/graphql -H 'content-type: application/json' \
  -d '{"query":"{ posts { edges { node { title } } } }"}'
```

The database is `memory()`: it starts empty at each start.
